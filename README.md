# ERNESTYT Segment Downloader

A lightweight, locally hosted YouTube segment downloader with a minimal red-and-white Ernest-branded interface.

Paste a video URL, choose your start and end timestamps, and download only the selected segment.

### Features
- Timestamp-based segment selection
- Best available video and audio quality
- No fixed 1080p resolution cap
- Localhost web interface
- Customizable background image
- Download progress tracking
- Show video in folder shortcut
- Download another video button
- Built-in duration verification
- Custom ERNESTYT favicon and branding

Built with Python, Flask, yt-dlp, and FFmpeg.
